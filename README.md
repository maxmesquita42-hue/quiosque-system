# Quiosque

Projeto inicial do sistema do Quiosque com identidade visual preta e laranja.

## Como abrir
1. Descompacte a pasta.
2. Instale Node.js.
3. No terminal, entre na pasta do projeto.
4. Rode:
   npm install
   npm start

## Arquivos
- frontend/index.html
- frontend/dashboard.html
- frontend/mesas.html
- frontend/produtos.html
- frontend/pedidos.html
- backend/server.js
- data/menu.json
- database.sql
- assets/logo.png
